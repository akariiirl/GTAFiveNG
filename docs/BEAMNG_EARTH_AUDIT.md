# BeamNG.Earth techniques for Project Los Santos

Reviewed 2026-11-17 against `TecnaGamer/BeamNG.Earth` commit `f51896f` and the locally installed unpacked mod. SHA-256 of the installed and source `core.lua`, `roads.lua`, and `map3d.lua` matched. The [project license](https://github.com/TecnaGamer/BeamNG.Earth/blob/main/LICENSE) is MIT. This audit describes behavior in that source; it does not establish that GTA geometry streams correctly in BeamNG.

| Area | Implemented in BeamNG.Earth | GTA adaptation and limit |
| --- | --- | --- |
| Player position | `core.lua` reads `veh:getPosition()` and velocity each update; `rebase.lua` changes the local origin after long travel. | Track the vehicle in a fixed GTA XY frame using the composed level origin. A floating origin is unnecessary for the present 2.3 × 2.6 km rectangle and would complicate existing collision transforms. |
| Near objects | `roads.lua` creates `TSStatic` and `DecalRoad` objects under frame budgets, then calls `:delete()` when tiles leave range. | Reuse the BeamNG API pattern, with reference counts because one converted mesh can cross several 256 m cells. The existing `chunk_prototype.lua` prefab adapter was mock-tested only and is not evidence of engine unloading. |
| Collision | `roads.lua` keeps collision closer than visuals, leads the active region with speed, calls `be:reloadCollision()`, and guards unavailable ground. | Load YBN collision before letting the vehicle enter a new cell; rebuild collision after changes. The current GTA package contains 135.9 million collision triangles, so full-scene rebuild cost and memory recovery must be measured in game. The prototype initially loads complete cell collision and pauses before an unready cell. |
| Terrain and limits | `terrain.lua` moves an actual heightfield physics block; `edgeguard.lua` holds the car if that ground cannot follow. | GTA roads and YBN meshes are not a heightfield. A BeamNG.Earth terrain swap cannot be transplanted without a new, validated GTA terrain product. A deliberate pause before an unloaded cell is safer than an invented collision wall. |
| Distant visual and LOD | `farfield.lua` streams lower-detail tiles separately from near roads/buildings; `governor.lua` budgets the work. | The 47-cell build has no validated distant-mesh library. Do not label hidden or unloaded high-detail objects as LOD. Build distant representations from GTA source only after near-cell engine behavior is proven. |
| Map | BeamNG.Earth uses a custom Vue map with geographic tile coordinates and a companion tile server; the native big map is not its whole-world renderer. | GTA uses local meter coordinates. The four-waypoint native map-bounds ZIP is a small, untested camera-range fix. An unloaded-world map needs a separate cached imagery/road layer or validated low-detail geometry; copying Earth latitude/longitude or its external data sources is unnecessary. |
| Memory | Earth removes scene objects and evicts server-side tile data; its source contains resource and frame-budget controls. | `:delete()` does not by itself prove DAE, texture, physics, or VRAM recovery in this GTA level. Compare process RAM, VRAM, collision-cache counts, and reload times before claiming bounded memory. |

The source experiment at `src/lsf_stream.lua` and local `streaming-probe-04/los-santos-stream-probe.zip` uses the existing 47-cell asset library and per-cell object manifests. Isolated BeamNG tests on 2026-11-17 confirmed that the level starts with an empty geometry scene, loads a 1,003-object spawn cell before releasing its pause, preloads neighboring cells, removes distant objects from the scene, and rebuilds collision. A six-meter drive crossed one technical-cell boundary without damage. Position-delta prediction fixed a stale startup velocity; budget-triggered eviction fixed a later preload deadlock. Physical memory fell by 0.43 GiB after a reverse unload transition, but total GPU memory did not fall measurably. Long drives, high-speed transitions, full VRAM release, and distant LOD remain unverified. The native big map displayed loaded geometry only. The probe contains all original art resources but does not assign the 739 objects whose bounds fall outside all 47 selected technical cells.
