# Licensing and local distribution

GTA V assets remain Rockstar/Take-Two proprietary content. Ownership of the installed game does not grant redistribution rights. Exported resources and converted ZIPs are private local experiments; do not publish them or put them in public repositories.

BeamNG is proprietary software; this project reads its installed examples to target supported level formats. It does not redistribute game binaries or copy an entire stock map.

CodeWalker upstream: https://github.com/dexyfex/CodeWalker , pinned commit `485d56bec00262ed7fa472261cce7bbc6202b96e`. Several source files carry individual license notices. Dependency source is retained in ignored `vendor/CodeWalker`; no blanket relicensing claim is made. Review upstream rights before distributing a compiled converter.

SharpDX dependencies: version 4.2.0, restored through NuGet. Python/NumPy and .NET remain external dependencies. New project code is unlicensed pending the user's distribution decision.

No DRM patch, original archive rewrite, game executable modification, public upload, or license bypass is part of this pipeline. CodeWalker is used for read-only local resource conversion.
